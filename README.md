# wellfound-apply-helper

A local-first toolkit for filling out Wellfound (formerly AngelList Talent)
internship / new-grad applications faster — **without** writing the same
"What interests you about working for this company?" essay from scratch 100
times.

The core pieces:

1. **A FastAPI dashboard** running on your machine (`localhost:9876`) that
   keeps a backlog of jobs you've discovered, with a pre-written blurb per
   job (generated by an LLM grounded in *your* projects).
2. **A "Fill smart" bookmarklet** you drop into any Chromium-based browser
   (Chrome / Edge / Brave / Arc). When you click Apply on a Wellfound job,
   click the bookmarklet — it scans every textarea in the apply modal,
   generates a question-specific answer for each, fills them, and starts
   watching for the success banner. When you click *Send application*, the
   dashboard auto-marks the bundle as submitted.

The intended workflow:

```
  Wellfound search          dashboard (localhost:9876)
        │                          │
        ▼                          │
  click Apply  ───────► bookmarklet ◄──► localhost backend (your data)
        │                          │
        ▼                          │
  textareas auto-filled            │
        │                          │
        ▼                          │
  you review + click Send  ──watcher detects "Congrats!"──► dashboard
        │
        ▼
  application sent
```

## What this is NOT

- **Not an auto-submitter.** The "Send application" click is always yours.
  The tool fills the form; you decide whether to send it.
- **Not a scraper of your contacts / a spam tool.** It only operates on
  pages you visit, using your existing logged-in browser session.
- **Not Wellfound-affiliated.** This is a third-party userscript.

## Setup (5 minutes)

### Requirements

- Python 3.10+
- A Chromium-based browser (Chrome, Edge, Brave, Arc)
- An OpenAI API key (for blurb generation)

### Steps

```bash
git clone https://github.com/etherimirr/wellfound-apply-helper
cd wellfound-apply-helper
pip install -r requirements.txt

# 1. Tell the tool who you are
cp profile.example.json profile.json
$EDITOR profile.json   # fill in name / school / email / GitHub / visa / etc

# 2. Tell it about your projects (= what to talk about in blurbs)
cp -r projects.example projects
$EDITOR projects/*.md   # one .md per project, see schema below

# 3. Tell it your OpenAI key
echo "sk-..." > .openai_key

# 4. Start the dashboard
python wellfound_dashboard_server.py
# opens http://localhost:9876
```

In the dashboard's top banner, **drag the orange ⚡ Fill smart button**
onto your browser's bookmark bar. (Press <kbd>⌘+Shift+B</kbd> / <kbd>Ctrl+Shift+B</kbd>
if you can't see the bookmark bar.)

That's the whole install.

## How to use

1. Open Wellfound, search for jobs you'd actually apply to.
2. Click **Apply** on any job — Wellfound's apply modal/panel opens.
3. Click the **⚡ Fill smart** bookmarklet you installed.
4. The bookmarklet:
   - extracts each textarea's question prompt
   - sends them to your local backend
   - backend generates an answer per question, grounded in *your* projects
   - fills every textarea
5. Review the answers. Edit anything you want.
6. Click **Send application** on Wellfound.
7. The bookmarklet watches for the "Congrats!" success banner and tells
   the dashboard. The bundle moves to your "Submitted history" section.

## profile.json schema

This file holds the things every blurb needs to reference about you. The
LLM gets it as context for every generation call.

See [`profile.example.json`](profile.example.json) for a fully-commented
template. Required fields:

| Field | Example |
|---|---|
| `name` | `"Your Name"` |
| `degree` | `"M.S. Computer Science"` |
| `school` | `"Your University"` |
| `grad_date` | `"May 2026"` |
| `email` | `"you@example.edu"` |
| `github` | `"your-github-handle"` |
| `location` | `"NYC"` |
| `visa_status` | `"F-1 (CPT eligible)"` or `"US citizen"` |
| `stack` | `"Python, FastAPI, React, AWS"` (your top-level summary) |

## projects/ folder schema

Each project is one Markdown file in `projects/`. The filename (minus
`.md`) is the project ID the picker uses. Inside, the LLM expects:

```markdown
# Project: my_project_id

## Header
One-line description (one sentence). Example:
"Acme Corp — Backend Engineer Intern (Summer 2025)"

## Tags
python, fastapi, postgres, distributed-systems

## Bullets
- Specific, concrete bullet with a real number or component name.
- Another specific bullet. Don't write "improved efficiency".
- Cite tech / tradeoffs / outcomes you can defend in an interview.

## Gates
brand: true                    # surface as a brand-name pick when relevant
only_for: []                   # leave empty to surface for any role
                               # or: ["game studio", "pure frontend"] to gate
```

See [`projects.example/`](projects.example/) for two real examples.

## Cross-platform notes

| Feature | macOS | Windows | Linux |
|---|---|---|---|
| Fill smart bookmarklet | ✅ | ✅ | ✅ |
| Dashboard (FastAPI) | ✅ | ✅ | ✅ |
| Blurb generation | ✅ | ✅ | ✅ |
| Auto Open & Fill (Playwright launcher) | ✅ | ✅ | ✅ (set Chrome path via env var) |

The bookmarklet path works in any Chromium browser on any OS. The optional
Playwright-driven "Auto Open & Fill" needs Chrome installed — if it's not
at the default path, set `WELLFOUND_HELPER_CHROME_PATH=/path/to/chrome` in
your environment.

## Security & privacy

- Your `profile.json`, `projects/`, OpenAI key, and discovered application
  bundles are all **stored locally**. Nothing is uploaded anywhere except
  to the OpenAI API endpoint you control.
- The bookmarklet only ever talks to `localhost:9876` (your own machine).
  Wellfound never sees your private data.
- `auto_apply_wellfound/` (the bundle directory) is gitignored by default
  — don't commit it.
- **Do not push your filled-in `profile.json` or `projects/` to a public
  fork.** They contain your personal application narrative.
